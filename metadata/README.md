# Metadata

This folder contains course-management information rather than learner-facing
lesson material:

- `WEEKLY_PROGRESS.md` — current resume point and completion evidence
- `COURSE_ROADMAP.md` — approved phases, confidence gates, required lanes,
  specialization/market policy, and upstream contribution outcome
- `curriculum-tracker.docx` — authoritative curriculum sequence
- `AGENT_CONTEXT.md` — teaching preferences and operational decisions
- `MASTERCLASS.md` — detailed historical handoff and prior checkpoints

Start learning from the numbered topic folders at the repository root.
